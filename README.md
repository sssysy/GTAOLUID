## 丨命令列表

### 账户相关
| 命令 | 说明 |
|------|:------:|
| `gta绑定 I-xPsycho-I` | 绑定 GTAOL 游戏账号 |
| `gta解绑` | 解绑指定游戏ID |
| `gta查看` | 查看已绑定的 GTAOL 账号列表 |

### 数据查询
| 命令 | 说明 |
|------|:------:|
| `gta总览` | 查看玩家资产与数据总览卡片 |
| `gta收支差` | 查看玩家详细收支差数据 |
| `gta玩家详情` | 查看玩家细项数据详情卡片 |
| `gta刷新数据` | 重新拉取主账号的最新数据 |
| `gta查封禁 I-xPsycho-I` | 查询指定玩家的战眼封禁状态 |

### 社区差事
| 命令 | 说明 |
|------|:------:|
| `gta差事推荐` | 查看当前热门社区差事推荐列表 |
| `gta上周热门竞速差事推荐` | 按筛选查差事推荐 |
| `gta差事详情 1` | 查看推荐列表中指定编号差事的详情 |

### 其他服务
| 命令 | 说明 |
|------|:------:|
| `gta帮助` | 呼出本插件帮助菜单 |
